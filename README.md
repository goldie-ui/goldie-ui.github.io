# 플레이그라운드 🎡

의존성 없이 브라우저에서 바로 열어 즐기는 작은 웹 프로젝트 모음입니다. 빌드 과정도, 설치도 필요 없어요 — HTML 파일 하나면 됩니다.

## 담긴 것들

| | 프로젝트 | 설명 |
|---|---|---|
| ⏱️ | [집중 타이머](timer.html) | 뽀모도로 타이머 + 할 일 목록. 세션 수와 할 일은 브라우저에 자동 저장됩니다. |
| 🎨 | [하모노그래프 캔버스](canvas.html) | 마우스를 움직여 흐르는 곡선 예술을 그리고 PNG로 저장하세요. |
| 🎮 | [2048](game.html) | 같은 숫자를 합쳐 2048을 만드는 퍼즐. 되돌리기/다시하기 지원. |

[index.html](index.html)이 세 가지를 모아 보여주는 시작 페이지입니다.

## 실행 방법

브라우저에서 `index.html`을 여는 것만으로 충분합니다.

```bash
open index.html
```

로컬 서버로 띄우고 싶다면:

```bash
python3 -m http.server 8000
# 그런 다음 http://localhost:8000 접속
```

## 조작법

- **집중 타이머** — `Space`로 시작/일시정지, 모드 버튼으로 시간 전환
- **하모노그래프** — 마우스 이동 또는 드래그로 그리기, 화면에서 저장 버튼
- **2048** — 화살표 키 · `WASD` · 스와이프로 이동, `Z` 되돌리기 · `Y` 다시하기

## 기술

순수 HTML · CSS · JavaScript. 프레임워크나 외부 의존성이 없습니다. 모든 데이터는 브라우저의 `localStorage`에만 저장되며 어디로도 전송되지 않습니다.
